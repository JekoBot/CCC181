# Requirements

Functional requirements (FR) for UniformQ, a queue app for claiming PE uniforms at the Langkit University Shop. Written in Week 3, and referenced by the personas, wireframes and code.

| ID | Requirement | Screen |
| --- | --- | --- |
| FR-01 | A student can join the queue with their name, section, items and sizes | Join |
| FR-02 | A student can see their queue number and how many people are ahead | My place |
| FR-03 | The app rejects incomplete or invalid forms with a clear message | Join |
| FR-04 | Staff can see the waiting list in queue order, with each student's name, section, items and sizes | Staff dashboard |
| FR-05 | Staff can call the next student, mark them served, or mark them no-show | Staff dashboard |
| FR-06 | A student's status updates without refreshing the page | My place |
| FR-07 | A student can leave the queue | My place |
